# LyricRacer-Web-Development
Web-based lyric typing game 
Go to https://console.cloud.google.com/ and create a project. From the Project, go to YouTube Data API v3 and generate a Oauth 2.0 Client ID. Save the client ID and client secret. Set Callback in Authorized redirect URLs. You'll also need Yotube Data API v3
